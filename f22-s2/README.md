# 中央AI5｜S45A F22-S2 大量統計安全原型

**僅本機假資料，尚未正式部署。此目錄不接任何現有 Worker Router、D1/R2、Cron、會員庫或 AI。**
本批從 GitHub main 建立全新安全分支；舊 F22-S1 PR #459 保留原狀。schema.sql 只供本機 SQLite 使用，**不是正式 migration**。

## 功能與維護原則
- 以不含個資的 event_key（穩定來源事件碼）、source_version 與 payload_hash 判斷重送、過期與修訂。相同版本同內容不重複入帳；同版本衝突全部回滾；明確較新的版本可訂正狀態、日期、音檔或撤銷。
- 每筆更新在本機單一交易維持「事件正本／每日計數／每日及全期假名會員出現次數」。跨日與跨音檔的會員人數是**真正去重**，不可把每日獨立人數相加。可處理 60,000+ 件，而不需舊 F22-S1 全期只取 6,000 件的限制。
- 時區採台灣 UTC+8；新事件取發生日時段，舊事件事後補傳亦可回補原本日期。保留最終版計數，避免不同裝置的同一請求重送。
- 會員鍵須由未來可信中央 Starry ID 後端以 **HMAC-SHA-256+秘密金鑰**產生；不可直接 SHA256 姓名、Email，也不將秘鑰/原始問題傳至瀏覽器。測試只用虛構人物 SHA256。資料保存／撤回同意後的身份連結清除政策需另批確認。
- 僅示範假中央超管（已驗證/active/super-admin/新鮮）可看去識別聚合。真正權限檢查仍應沿用中央最新有效 membership，其他身份拒絕。不輸出會員識別碼、Email、私人原始問題。
- B07 的 held 預留不是 settled 實際供應商成本；實際費用、Token、延遲、跨事件重複時間間隔無真資料時全部 **null**，不假設 0。講者／多講者歸屬仍待與舊 F22-S1 統一。

## 全帳號免費額度與安全停止（僅 Fake 規劃）
Cloudflare Workers Free D1 參考：每日讀 500 萬列、寫 10 萬列（全帳號所有 App 合計），官方 https://developers.cloudflare.com/workers/platform/pricing/ 。
- 任何讀取 ≥400 萬或寫入 ≥80,000：橘色 **停止非必要新統計批次**。
- 任何讀取 ≥500 萬或寫入 ≥100,000：紅色 **停止全部新統計批次**。
- 帳戶用量未知、觀測時間超過 5 分鐘：灰色，**禁止新統計批次**。
- 單批最多 256 筆。先以 **假設**每筆最多 64 rows_read、32 rows_written 預留風險；這個數字不是實際 D1 計費測量，也未包括索引成本，不能拿來保證免費。實際接入前必須量測 D1 meta.rows_read/rows_written、跨 App 併發、重試/回填、Workers CPU、共同配額來源延遲與事件版本。
- 大量測試若超過 80% 就整批暫緩，模擬次日重試，**不會自動開 Cron 或讀真雲端用量**。


## **尚未解決的正式上線阻擋**
1. 本原型 FakeSqlite 使用本機 `BEGIN IMMEDIATE`；未設計真 D1 多 Worker 同時寫入/原子条件/跨多 API 的可靠交易，亦未接 PR #459 Router/正式 Starry ID、沒有真人超管登入驗收。
2. 假元資料需由可信來源提供不可回捲的 request ID、來源版本和會員鍵；如果跨裝置不共用相同事件鍵，無法自動推斷是否同一次請求；資料不可靠須拒絕。
3. 真實全帳號已用額度、索引計費、2000 人實際併發未驗；每日預估讀寫僅做離線演算。不承諾零元或已生產可用。
4. #459 仍 Draft，F23 僅可寫私密聚合契約，**F24 公開榜、撤回、CDN/PWA 快取安全不在本次授權，不得接 API**。
5. PR CI/Preview 只代表安全版建置，不能改雲端資源、正式 migration、合併 main 或 Production。後續與 AI2/AI3/AI7 對接須分批再授權。
