# P1-A 完整離線模擬版

**僅供驗收，不是正式管理後台。**

## 如何預覽
1. 在 GitHub 草稿 PR #482 找到 `docs/p1a-offline-demo/index.html`。
2. 下載該 HTML 檔案。
3. 用 Chrome 或 Safari 直接開啟；斷網也可以操作。

## 驗收項目
- 六個分頁：總覽、AI3 費用、AI4 搜尋、AI5 統計、AI6 安全、AI7 備份。
- 費用：假設預算和低／中／高情境只在本頁試算，正式預算仍為 NT$0。
- 搜尋：只搜尋虛構音檔，清楚保留 47.5% 未達標提示。
- 統計：切換 7／30 天及全期，資料全部為合成示例。
- 安全：四域獨立；切換狀態僅為展示，不解鎖任何正式功能。
- 備份：版本切換可讀，還原及刪除按鈕不可操作。
- 手機與桌面均能使用，鍵盤可切換分頁與輸入。

## 安全邊界
- 不含外部套件、CDN、遠端腳本、圖片、字型。
- 不發送 API 請求，不使用正式會員、逐字稿、帳單、資料庫或雲端資源。
- 不存取 Cookie、localStorage 或 sessionStorage。
- 本檔放在獨立 `docs/` 路徑，不會自動加入正式網站路由。
- 所有安全狀態僅示範，不能作為正式權限或安全驗證依據。

## 檢查
`npm test` 將包含 `tests/p1aOfflineDemo.test.ts` 的靜態隔離檢查。這不能取代瀏覽器人工驗收。
